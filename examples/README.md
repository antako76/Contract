# examples

Small executable examples that demonstrate public API usage.

Available targets:

- `contract_example_smoke` - minimal contract object round-trip to console
- `contract_example_console_dump` - schema/value console dump example
- `contract_example_hero_roundtrip` - full schema/debug/binary round-trip example from the landing page
- `contract_example_logging` - structured newline-delimited JSON logging example
- `contract_example_yaml_file_read` - read a YAML config from a file and print it to console
  - default file: `examples/yaml/payment_config.yaml`
